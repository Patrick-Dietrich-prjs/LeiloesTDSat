Sistema de Leilões

O Sistema de Leilões é uma aplicação desktop desenvolvida em Java com interface gráfica para gerenciamento de produtos destinados a leilão. O sistema permite o cadastro de novos produtos e a listagem/consulta dos produtos já cadastrados, exibindo informações como ID, nome, valor e status.

Funcionalidades principais

Cadastro de novos produtos
Listagem de produtos cadastrados em tabela
Consulta de vendas (em desenvolvimento)
Venda de produtos por ID (em desenvolvimento)


Tecnologias utilizadas

Java (Swing / AWT para interface gráfica)
MySQL (banco de dados relacional)
JDBC (conexão entre a aplicação Java e o banco de dados)
NetBeans (IDE utilizada para geração dos formulários gráficos)
